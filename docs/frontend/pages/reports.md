# Page Spec — Reports

**Route:** `/admin/reports`
**Component:** `src/pages/governance/ReportsPage.tsx`
**Persona:** Governance (ITAdmin + Auditor both have write access per backend: `AuditViewPolicy` covers read, and the generate endpoint allows both)
**Status:** Ready for implementation

---

## 1. Purpose

Generate and download analytics reports (Enrollment, Revenue, GPA). List of previously generated reports. Simple surface — the value is in the download, not the UI.

---

## 2. API

```
GET  /api/reports?scope={s}&limit=20     — list reports
POST /api/reports/generate               — { reportType, scope, data }
GET  /api/reports/{id}/download          — download report data
```

## 5. Download button

`[Download ↓]` → `GET /api/reports/{id}/download`. Response is JSON data. For v1: trigger browser download as `.json` file using same Blob approach as payments CSV. For v2: backend can return formatted PDF/XLSX.

```ts
const handleDownload = async (reportId: number, reportType: string) => {
  const data = await api.get(`/reports/${reportId}/download`)
  const blob = new Blob([JSON.stringify(data, null, 2)], { type: 'application/json' })
  const url = URL.createObjectURL(blob)
  const a = document.createElement('a')
  a.href = url
  a.download = `${reportType.toLowerCase()}-report-${reportId}.json`
  a.click()
  URL.revokeObjectURL(url)
}
```
