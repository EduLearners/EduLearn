# Page Spec — Transcript

**Route:** `/transcripts/:id`
**Component:** `src/pages/learner/TranscriptViewPage.tsx`
**Persona:** Learner (own only), Registrar/ITAdmin (any student)
**Status:** Ready for implementation

---

## 1. Purpose

Read-only academic transcript. View issued transcript and download as PDF. Issued transcripts are immutable — no editing affordances shown to anyone.

---

## 2. API

```
GET /api/transcripts/student/{me}    — list student's transcripts
GET /api/transcripts/{id}           — specific transcript with EntriesJSON, GPA, status, TranscriptURI
```

---

## 4. Status badge

| Status | Bg | Text | Meaning |
|---|---|---|---|
| Draft | `neutral-100` | `neutral-600` | Not yet issued, may change |
| Issued | `success-50` | `success-500` | Official, immutable |
| Revoked | `danger-50` | `danger-500` | Invalid — show revocation notice |

---

## 5. Download PDF button

Visible only when `status === 'Issued'` AND `transcript.transcriptUri` is non-null.

```jsx
<Button
  variant="outline-primary"
  href={transcript.transcriptUri}
  target="_blank"
  rel="noopener noreferrer"
  aria-label="Download transcript as PDF"
>
  <i className="bi bi-download me-2" aria-hidden="true" />
  Download PDF
</Button>
```

Opens PDF in new tab (browser PDF viewer). Does not trigger JS download — the URI is a direct PDF link generated by the backend (QuestPDF).

---

## 6. Immutability notice

Always visible on Issued or Revoked transcripts. Renders as a neutral info block below the table:

```jsx
<div className="transcript-notice" style={{background: 'neutral-50', borderRadius: '8px', padding: 'space-6', marginTop: 'space-8'}}>
  <i className="bi bi-lock me-2 text-muted" aria-hidden="true" />
  <span>This transcript was issued on {issuedDate} and is a permanent record.
  Contact your registrar if you need corrections.</span>
</div>
```

Not an `<Alert>` component — this is a calm informational note, not a warning. No color accent.

---

## 7. Revoked state

```
Status: [Revoked]

This transcript was revoked on Nov 15, 2026.
Contact your registrar for a re-issued copy.

[Contact registrar →]  ← navigates to /tickets/new with subject pre-filled
```

Grade table still visible (historical record), but watermarked or visually de-emphasized (opacity 0.5, `pointer-events: none`).

## 8. Draft state (student view)

Status: [Draft]

No download button. Table visible as preview.

## 9. A11y

- `<table>` with `<caption>` "Academic transcript for Aarav Mehta, BSc Computer Science"
- `<th scope="col">` for all column headers
- Credit and GPA values: `aria-label` on totals row ("Total 12 credits, Cumulative GPA 3.40")
- Status badge: `aria-label="Status: Issued"` — screen reader reads "Issued" not just the color

---

## 10. Responsive

<640px: course name truncates with title tooltip. Credits/Grade/Term columns stay visible. Table horizontal scroll if needed.

---

## 11. Implementation notes

1. `EntriesJSON` from API: `[{courseCode, courseTitle, credits, grade, term}]`. Sort by term ascending (chronological).
2. GPA from `transcript.gpa` field — not recomputed. Display with `toFixed(2)`.
3. Registrar/ITAdmin view: same component, different API call (`GET /api/transcripts/{id}` directly). Action bar shows "Issue" or "Revoke" buttons conditionally — per routes.md, these are Registrar-only actions.
4. Do not load all transcripts and filter — request the specific transcript by ID from the URL param.
